# mRemote プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-11-05

## 日本語

mRemote(以下「本アプリ」)は、リモートデスクトップ(RDP)と SSH のクライアントです。開発者は mikuta0407 です。

### 収集する情報

本アプリは、利用者の情報を収集しません。開発者や第三者のサーバーに情報を送ることはなく、利用状況の分析、広告、トラッキング、クラッシュレポートの送信も行いません。

### 端末に保存する情報

次の情報は、利用者の端末の中にだけ保存します。

- 接続先の設定(表示名、ホスト名、ポート、ユーザー名、画面や入力の設定、プロキシの設定など)
- パスワード、SSH の秘密鍵、信頼した証明書と SSH のホスト鍵(iOS / macOS のキーチェーンに保存します)
- アプリの表示や操作の設定

これらは iCloud などで同期しません。本アプリを削除すると、端末から消えます(macOS 版では、接続先の設定ファイルとキーチェーンの項目が残る場合があります)。

### 通信

本アプリが通信するのは、利用者が指定した接続先(および利用者が設定したプロキシや SSH の踏み台)だけです。画面、キーボードやマウスの入力、クリップボード、音声、マイク、共有したフォルダーの内容は、利用者が操作したとき、その接続先とのあいだでだけやり取りします。

### マイク

接続先のマイクを利用者がオンにしたときだけ、マイクの音声を接続先に送ります。録音して保存することはありません。

## English

mRemote (the "app") is a Remote Desktop (RDP) and SSH client, developed by mikuta0407.

### Information collected

The app collects no information about you. It sends nothing to the developer's or any third party's servers, and has no analytics, advertising, tracking or crash reporting.

### Information kept on the device

The following is kept only on your device:

- Connection settings (names, host names, ports, user names, display and input settings, proxies)
- Passwords, SSH private keys, trusted certificates and SSH host keys (in the iOS / macOS Keychain)
- The app's own display and input settings

None of it is synchronised through iCloud or elsewhere. Deleting the app removes it from the device (on macOS, the connections file and Keychain items may remain).

### Network

The app connects only to the computers you choose, and to the proxies and SSH jump hosts you set up. The screen, keyboard and pointer input, clipboard, audio, microphone and shared folders pass only between the app and that computer, when you use them.

### Microphone

The app sends microphone audio to the remote computer only while you have turned its microphone on, and never records it.
